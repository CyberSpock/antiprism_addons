# Antiprism Addons

Additional polyhedral geometry tools for
[Adrian Rossiter's Antiprism](https://www.antiprism.com/), maintained by
Roger Kaufman. This beta distribution provides 17 Python commands.

Many commands rely on existing Antiprism executables, which **must be
installed separately** and available on `PATH`.

For installation instructions, current generated command help, examples,
and the separately built C++ utilities, visit the
[Antiprism Addons repository](https://github.com/CyberSpock/antiprism_addons).

The optional `stella` command requires `STELLA_EXE` to point to a Stella
executable. `offview` and `x3dview` use browser viewers hosted externally;
model content is served from the machine running the commands via localhost.
